## Day 01 （第一次尝试）· 2026-11-01

- 学了：交互模式（REPL）怎么进、怎么退——终端敲 `python3`，出现 `>>>` 就是进来了；`exit()` 或 ⌃D 退出
- 试了：`2**10` → 1024；`7/2` → 3.5；`7//2` → 3（`//` 是整除）
- 卡住：在 zsh 里直接敲 2**10，报 zsh: no matches found——因为 `*` 是命令行通配符，得先 python3 进解释器
